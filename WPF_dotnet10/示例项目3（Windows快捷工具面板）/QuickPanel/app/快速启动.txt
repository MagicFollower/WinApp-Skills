开发构建（需要本机装有 .NET 10 SDK，dotnet --list-sdks 能看到 10.x）
  dotnet build .\QuickPanel.csproj

直接运行
  dotnet run --project .\QuickPanel.csproj

一键打包单 exe（上级目录两个脚本，产物文件名带模式后缀）
  publish.cmd            → ..\publish\QuickPanel_self_contained.exe  实测 70,290,088 B（约 67 MB），
                           运行时在包里，目标机免装 .NET
  publish_no_runtime.cmd → ..\publish_no_runtime\QuickPanel_no_runtime.exe  实测 1,674,934 B（约 1.6 MB），
                           但目标机必须先装 .NET 10 Desktop Runtime（dotnet --list-runtimes 看得到
                           Microsoft.WindowsDesktop.App 10.x 就行）

设置自测（退出码 = 失败断言数，0 为全通过）
  QuickPanel_self_contained.exe --selftest
  报告写到 %APPDATA%\QuickPanel\selftest.txt

换应用图标
  覆盖 app\AppIcon.ico 即可（csproj 的 ApplicationIcon 与 Resource 两处都指它）；
  默认图标是本地生成的首字母像素图标，换字母或配色重跑 Skill 的 make-icon.ps1：
    powershell -NoProfile -ExecutionPolicy Bypass -File "<skill>\scripts\make-icon.ps1" -Name QuickPanel -Out app\AppIcon.ico
  有 ImageMagick 也可以：magick 源.png -define icon:auto-resize=256,64,48,32,16 AppIcon.ico
  换完要重新构建，并用 ExtractAssociatedIcon 取回内嵌位图逐像素比（体积不是判据）

改观感配色
  只改 app\Helpers\Theme.cs 的常量，然后跑 --selftest 看对比度断言有没有红

用户能自己改的东西（都已接好，改文案就改 Views\SettingsOverlay.xaml）
  右上角齿轮 → 设置浮层：应用信息 / 配色 / 字体（族 + 正文字号）/ 全局缩放，Esc 或点遮罩关
  落盘位置 %APPDATA%\QuickPanel\settings.json（kv1 纯文本，能自己开编辑器改，越界值会被钳回区间）
  默认值与允许区间只有一个出处：app\Helpers\Typography.cs（基准 15、字号 12-28、缩放 50-200）
  可选配色档由 Helpers\Theme.cs 的 Policy 决定（both / light-only / dark-only），
  留在 "TODO" 时 --selftest 会红并被发布脚本挡下

加 / 改一个快捷入口（本项目最常做的改动）
  数据源只有一个出处：Services\ToolCatalog.cs 的 Items 数组，一行一张卡片：
    I("mmc", "服务", "services.msc", "启动、停止、重启服务并设置启动类型", admin: true, probe: "services.msc")
  分组要新增就同时改 ToolCatalog.Groups（key/标题/图标码位，顺序即左栏顺序）——卡片的"所属大类"标签
  在建项时由 GroupTitleOf(key) 现填进 ToolItem.GroupTitle，所以新分组不用改界面代码。
  右栏是常驻的：十一个导航项的 Content 都指向同一个 SectionShell（不是各自的 ToolSection），
  切换只改各节 IsActive 翻 Visibility，容器不重建——这是"切到全部工具不再卡"的机制，
  别改回 Content=section。导航项用宿主自己的 NavSectionItem（覆写 ToString 返回分组标题），
  改回基类会让读屏与按名字点导航项的脚本拿到 "StartUI4Controls.UI4NavigationViewItem"。
  六个可选参数各自的含义：admin=需要 UAC 提权；homeMissing=家庭版 SKU 根本没这个文件（与提权是两回事）；
  compat=Win10/Win11 行为不一致时写进卡片标签；danger=危险提示（本项目按"单击直接执行"的决策，
  危险项只靠卡片文案提醒，不弹确认框）；probe/probeKind=本机探测（.cpl/.msc/.exe 结尾的命令才给，
  ms-settings、shell: 这类由 Shell 解析的不给；cmd /k …、powershell … 起头的也不给——
  powershell.exe 根本不在 System32，探测挡位配错了会误报"本机未找到"）。
  改完必跑 --selftest：数据源那 27 条会点名钉住"命令唯一、介绍 10-48 字、探测挡位自洽、
  家庭版缺失项集合一致、不含实测不存在的误传命令（input.cpl / wmic.exe / telephonc.cpl 等 17 个）、
  分组标签的显示时机、IP 与 DNS 那 11 条、切分组只点亮一节、三块模板能实例化"。
  命令表怎么来的、依据哪些来源，见 doc\运行与构建（T0Level）.md 的 §7.0——别拿社区命令表直接抄；
  切换响应为什么这么接、改坏了怎么量回来，见同文 §7.3。
