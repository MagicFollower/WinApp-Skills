开发构建（需要本机装有 .NET 10 SDK）
  dotnet build .\PromptFavorites.csproj
  判据：0 个错误。警告恰好是上游 lib 自带的 9 条（CS0414×5 + CS1574×4）；
  如果报 0 个警告，多半是增量只重编了 app，请用 dotnet build .\PromptFavorites.csproj --no-incremental

直接运行
  dotnet run --project .\PromptFavorites.csproj

一键打包单 exe（上级目录两个脚本，产物文件名带模式后缀）
  publish.cmd            → ..\publish\PromptFavorites_self_contained.exe  约 67 MiB，运行时在包里，目标机免装 .NET
  publish_no_runtime.cmd → ..\publish_no_runtime\PromptFavorites_no_runtime.exe  约 2.4 MiB，
                           但目标机必须先装 .NET 10 Desktop Runtime（dotnet --list-runtimes 看得到
                           Microsoft.WindowsDesktop.App 10.x 就行）
  2026-10-04 第三批实测：70,607,724 字节 / 2,535,636 字节，两个目录各自只有一个 exe，
  FileVersion 都是 1.0.0.0（与 csproj 的 <Version>1.0.0</Version> 一致）。
  重打之前先删空 ..\publish 与 ..\publish_no_runtime，别拿上一轮产物验本轮改动。

配置的两层落点（2026-10-04 第七批）
  全局引导  %APPDATA%\PromptFavorites\settings.json
            → rootPath（上次用的根）+ 明暗档 + 排印三键 + 折叠态 + 窗口几何
  每根配置  <Prompt 根目录>\.PromptFavorites\settings.json
            → lastModule、sortMode/moduleSortMode、favoriteFilter、
              moduleCustomOrder/entryCustomOrder（只在这一根里有意义的那些状态）
  判据是"换个根目录，这个值还有没有意义"。成因与四条配套约定见设计方案 §22.1。
  三条实操须知：
  1) .PromptFavorites 不是模块：左栏不显示它，也不能拿它当模块名（新建与改名都会拒绝）。
  2) 从旧版升级不需要动手：第一次启动就把旧全局里残留的数据键接进本根，同时从全局摘掉；
     动之前建议自己留一份旧配置（本轮验证时留的是包内 .verify-backup-<时分秒>\settings.json）。
  3) 根目录不可写（只读盘、离线同步盘）时配置不会清零：数据键继续留在全局文件里当副本，
     设置面板"设置目录（当前根）"那行会标注当前处于回退态。
  入口：目录按钮的菜单里"打开设置目录（当前根）"与"打开全局设置目录"分别指这两层。
  自测凭什么验得到而不碰用户配置：SettingsService 有个 internal 的 SettingsService(globalDir)
  重定向入口，DataSelfTest 用它把全局侧也落进临时目录，所以换根/迁移/回退/损坏留档
  这几条是真读写文件跑出来的判据，不是纯函数推演。

设置面板（第三批新增）
  齿轮 → 应用信息 / 配色 / 字体 / 全局缩放；关掉浮层（完成、遮罩、Esc）时落盘一次。
  键名与区间：themeMode（Light|Dark，按名解析）、fontFamilyName（可空 = 出厂字体栈）、
  baseFontSize（12–28，默认 15）、zoomPercent（50–200，默认 100）。
  字号调的是基准，其余层级按 11/12/13/14/16 的阶梯跟随；缩放走根 LayoutTransform，
  窗口下限按系数折算。弹层（下拉、右键菜单）不随缩放放大，是 WPF Popup 的机制，已在 README 标为已知边界。
