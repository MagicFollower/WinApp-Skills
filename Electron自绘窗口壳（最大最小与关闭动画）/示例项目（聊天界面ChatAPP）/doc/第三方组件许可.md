# 第三方组件许可与取用记录

本工程渲染层含 **React Bits**（reactbits.dev，作者 David Haz）的 vendored 源码。
许可：**MIT + Commons Clause** —— 可自由使用与修改，但不得把组件本身作为商品单独再分发/出售；随本应用整体分发允许。署名按本文件记录，算交付项。

- 上游仓库：https://github.com/DavidHDev/react-bits
- 组件目录与文档：https://www.reactbits.dev/
- 取用变体：**TS-CSS**（本工程无 Tailwind，全部走纯 CSS 变体）
- 取用方式：`GET https://reactbits.dev/r/<Name>-TS-CSS` 取 registry JSON，`files[]` 原样落进 `src/components/bits/<Name>/`
- 取用日期：**2026-10-11**
- 本地改写原则：**组件源码保持与上游一致**，与本工程令牌冲突的部分统一在 `src/styles/app.css` 的「reactbits 动效层适配」段收口；JS 侧颜色经 `src/lib/palette.ts` 从 CSS 变量读取，`tokens.css` 仍是单一真源。

## 取用后评估未接入

| 组件 | 结论与实测依据 |
|---|---|
| **CountUp** | 大数字消息改回静态渲染。`damping=20+40/duration` 使其高度过阻尼、尾部渐近：`duration=0.7` 时发消息 2.6s 仍显示 9112/9178；`duration=2` 时 4.0s 仍显示 7278/7321。聊天消息长时间显示错误数字不可接受，且 `separator` 是千分位符（会把 9178 排成 "9 178"，与原型的字距排布不是一回事）。已从 `bits/` 删除该文件。 |
| AnimatedList | 自带行结构与 `@hugeicons/*` 图标集，属结构性替换，越出「动效层叠加」口径 |
| **Dock**（2026-10-11 为"右键浮出窗口控制条"查过） | 不接。registry 声明 `react-dom@^19`（本工程 React 18，装它要么升 DOM 要么吃 peer 冲突），且形态是底部停靠条 + 放大镜缩放动画，与"在光标处浮出三个横向按钮"不同题；`--crop` 实测自绘件 120×44 已达标 |
| **BubbleMenu**（同上） | 不接。它是链接型菜单（`items` 带 href/图标）且**自带开合内部状态**，要挂到"头部右键 + 跟随光标"必须改它的 vendored 源码，违反「组件源码保持与上游一致」；自绘一条 `.win-menu` 更省（CSS 约 30 行，零依赖） |
| GlassSurface | 会改左右卡片的边框/折射观感，偏离原型 |
| GlareHover | 30px 表情格上做 glare 是噪声 |
| SplashCursor / GhostCursor / CursorGrid | IM 不应替换系统光标；GhostCursor 还要 `three` |
| WarmTooltip | registry 声明 `react-dom@^19.0.0`，本工程 React 18 |
| PillNav | registry 声明 `react-router-dom`，本工程无路由 |

## 运行时依赖（由上述组件真实 import 决定）

| 包 | 版本 | 被谁需要 |
|---|---|---|
| `ogl` | ^1.0.11 | SoftAurora（WebGL） |
| `gsap` | ^3.15.0 | AnimatedContent（含 ScrollTrigger 插件）、FoldText |
| ~~`motion`~~ | ^12.43.0 | 曾为 BlurText；2026-10-11 撤下 BlurText 后**工程内再无引用**，包仍在 devDependencies（未卸，见下） |

三者均登记在 **devDependencies**（渲染层由 Vite 打进 `dist/`，主进程不 require），`dependencies` 保持为空。

`motion` 留在 devDependencies 是有意为之：它不再进产物（JS 已从 473.66 kB 降到 352.33 kB / gzip 163.88 → 124.04），但 `bits/BlurText/` 保留可回退，而本工程不是 git 仓库，卸包会让回退变成重装依赖。要彻底清掉就 `npm uninstall motion` 并删 `src/components/bits/BlurText/`。

GooeyNav **零依赖**：registry 的 `dependencies` 与 `registryDependencies` 都是空数组，它自带 WebGL2 SDF 管线（`canvas.getContext('webgl2')` + 手写 shader），不用 `ogl`。落盘后 `package.json` 未改动。产物增量：CSS +1.84 kB（gzip +0.46）、JS +16.40 kB（gzip +6.73）。

HoldButton 同样 **零依赖**（`dependencies: []`、`registryDependencies: []`，纯 React + CSS，不用 `gsap` 也不用 `motion`）。落盘后 `package.json` 未改动。产物增量：CSS 18.72 → **25.77 kB**（gzip 4.79 → 6.24）、JS 349.88 → **356.47 kB**（gzip 123.04 → 125.13）。
