# ls — 列出目录内容

> 列出文件与目录项；`-l` 输出长格式，`-a` 含隐藏项，`-t`/`-S`/`-X` 决定排序方式。

## 语法
```bash
ls [OPTION]... [FILE]...
```

## 常用选项
| 选项 | 说明 |
| --- | --- |
| `-a`, `--all` | 列出以 `.` 开头的隐藏项 |
| `-l` | 长格式：类型与权限、硬链接数、属主、属组、字节数、时间、名称 |
| `-h`, `--human-readable` | 与 `-l` 连用，大小按 K/M/G 显示 |
| `-t` | 按修改时间从新到旧排序 |
| `-S` | 按文件大小从大到小排序 |
| `-X` | 按扩展名字典序排序 |
| `-r`, `--reverse` | 反转当前排序方向 |
| `-d`, `--directory` | 只列目录本身，不进入列出其内容 |
| `-R` | 递归列出所有子目录 |
| `-1` | 每行一个名称，方便接管道 |
| `--color=WHEN` | `never` / `always` / `auto`，控制是否着色 |
| `--time-style=FORMAT` | 时间列格式，如 `long-iso`、`full-iso` |

## 示例
查看当前目录全部内容（含隐藏项）与可读大小：

```bash
ls -lah
```

按修改时间倒序看最近改动的日志：

```bash
ls -lht /var/log | head -20
```

只列出目录名而不进入它们，依赖 shell 通配符：

```bash
ls -d */
```

按文件大小从大到小排序（`-S` 比的是表观大小，不是磁盘占用）：

```bash
ls -lhS /home
```

用完整 ISO 时间戳核对配置文件的修改时间：

```bash
ls -l --time-style=full-iso /etc/hosts
```

每行一项，方便交给其他命令过滤：

```bash
ls -1 /etc/ssh | grep conf$
```

## 注意事项
- 不要用 `ls` 的文本来还原文件名：空格、换行、转义和 locale 都会破坏解析，脚本里改用 glob 或 `find -print0`。
- shell 通配符 `*` 不匹配 `.` 开头的文件，`ls */` 只给目录；想连隐藏项一起处理需要显式模式或 `-a`。
- 多数发行版给交互 shell 设了 `alias ls='ls --color=auto'`，脚本里 `ls` 的行为可能与终端里不同。
- 列出目录内容需要该目录的读权限，`ls -d dir` 只需要父目录权限；无权限时报 `Permission denied`。

## 相关命令
- `find` — 按名称、类型、时间递归查找
- `stat` — 查看单个文件的完整元数据
- `du` — 统计文件与目录占用空间
- `tree` — 树形展示目录层级（需另行安装）
