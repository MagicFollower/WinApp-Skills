# less — 分页查看文件与日志

> 边看边读的分页器：打开超大文件不会刷屏，可以前后搜索、过滤，还能跟踪追加写入。

## 语法

```bash
less [选项] [文件...]
命令 | less
```

## 按键

| 按键 | 说明 |
| --- | --- |
| `空格`, `f`, `^F` | 向下翻一页 |
| `b`, `^B` | 向上翻一页 |
| `j`, `k`, `回车` | 向下 / 向上滚动一行 |
| `g`, `G` | 跳到文件开头 / 文件结尾 |
| `50g`, `50%` | 跳到第 50 行 / 全文 50% 处 |
| `/关键词` | 向后搜索，`n` 下一个、`N` 上一个 |
| `?关键词` | 向前搜索 |
| `&关键词` | 过滤，只显示匹配的行 |
| `F` | 跟踪文件追加，按 `Ctrl-C` 停止跟踪 |
| `e`, `x` | 切换到下一个 / 上一个文件 |
| `q` | 退出 |

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-N` | 每行前面显示行号 |
| `-F` | 内容不足一屏时直接打印并退出，不进分页 |
| `-R` | 原样显示 ANSI 颜色，配合 `grep --color` 使用 |
| `-S` | 长行不折回，用左右方向键横向滚动 |
| `-i` | 搜索忽略大小写，模式里含大写字母时仍区分 |
| `-X` | 退出后不清屏，把最后看到的内容留在终端上 |

## 示例

带行号看系统日志，`/` 输入关键词后按 `n` 反复跳到下一个匹配：

```bash
less -N /var/log/syslog
```

直接从文件结尾开始跟踪，效果接近 `tail -f`，但可以随时按 `b` 往回翻历史：

```bash
less +F app.log
```

一次打开多个文件，用 `e` 往后、`x` 往前切换；`:t 文件名` 可以中途加载新文件：

```bash
less conf/*.conf
```

## 注意事项

- `F` 只对真实文件生效；`命令 | less` 时要等命令输出结束才有内容，也没有跟踪能力。
- less 用的是自带的正则实现，规则与 `grep -E` 并不完全一致；搜字面的 `.` 要写成 `\.`，复杂匹配建议先 `grep` 再管道给 less。
- 环境变量 `LESS` 会预置默认选项，行为对不上时先 `echo "$LESS"` 确认，命令行选项可以覆盖它。
- 终端被其他程序的输出弄乱时按 `R` 重绘，或直接重新打开文件。

## 相关命令

- `more` — 只能向前翻的极简分页器
- `tail` — 跟踪日志追加
- `grep` — 先检索出关心的行再分页
