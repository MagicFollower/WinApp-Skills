# wc — 统计行数、字数、字符数与字节数

> 默认同时报出"行数 单词数 字节数"三项，只关心其中一项时用 `-l`、`-w`、`-c`、`-m` 单独取。

## 语法

```bash
wc [选项] [文件...]
命令 | wc [选项]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-l`, `--lines` | 只统计行数，实际是数换行符的个数 |
| `-w`, `--words` | 只统计单词数，即被空白分隔开的可打印字符序列 |
| `-c`, `--bytes` | 只统计字节数 |
| `-m`, `--chars` | 只统计字符数，受当前区域设置影响 |
| `-L`, `--max-line-length` | 只输出最长行的宽度，制表符参与计算 |
| `-b` | `-c` 的历史别名，同样统计字节 |
| `--files0-from=F` | 从文件 F 读取以 NUL 分隔的文件名，配合 `find -print0` |

## 示例

看系统日志有多少行，顺带确认文件大小：

```bash
wc -l /var/log/syslog
```

统计项目代码行数，多个文件时最后一行是 `total`：

```bash
find src -name '*.ts' -print0 | xargs -0 wc -l
```

在 shell 里只要数字，用输入重定向就不会把文件名一起带进变量：

```bash
lines=$(wc -l < notes.txt)
```

中文文档里字节数明显大于字符数，差额来自 UTF-8 编码：

```bash
wc -m -c -L note.md
```

数命中行数有两种写法，结果一致但 `-c` 少开一个进程：

```bash
grep -c 'ERROR' app.log
grep 'ERROR' app.log | wc -l
```

## 注意事项

- `-l` 数的是换行符，末行不带换行时会少数 1 行；管道输入同样遵循这个规则。
- `-c` 是字节、`-m` 是字符，UTF-8 下一个汉字占 3 个字节但只算 1 个字符，两者相差几倍很正常。
- 文件不可读时 `wc` 会报错并跳过它，多个文件的 `total` 只累加成功读取的部分，别把报错的输出当成 0。
- `find ... | xargs wc -l` 在文件很多时会被 xargs 分批执行，结果里出现好几个 `total`，需要再对这些 `total` 求和才是真实总数。

## 相关命令

- `grep -c` — 统计匹配行数，不必先管道
- `du` — 看的是磁盘占用，不是文件字节数
- `sort | uniq -c` — 统计每个值出现的次数
