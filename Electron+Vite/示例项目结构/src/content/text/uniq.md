# uniq — 折叠相邻重复行并计数

> 把连续相同的行压成一行，`-c` 给出重复次数；先配合 `sort` 才能统计全文的重复情况。

## 语法

```bash
uniq [选项] [输入文件 [输出文件]]
sort 文件 | uniq [选项]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-c`, `--count` | 每行前面加上重复次数 |
| `-d`, `--repeated` | 只输出重复出现的行，每组打印一次 |
| `-D`, `--all-repeated` | 重复组里的每一行都输出，便于看清内容 |
| `-u`, `--unique` | 只输出没有重复过的行 |
| `-i`, `--ignore-case` | 比较时忽略大小写 |
| `-f N`, `--skip-fields=N` | 比较时跳过前 N 个字段，字段以空白分隔 |
| `-s N`, `--skip-chars=N` | 比较时跳过每行前 N 个字符 |
| `-w N`, `--check-chars=N` | 每行最多只比较前 N 个字符 |
| `-z`, `--zero-terminated` | 以 NUL 而不是换行分隔行 |

## 示例

统计访问来源 IP 的出现次数并排名，这是 `uniq` 最常见的用法：

```bash
cut -d' ' -f1 access.log | sort | uniq -c | sort -nr | head
```

只挑出写了不止一次的行，确认哪些记录是重复导入的：

```bash
sort hosts.txt | uniq -d
```

反过来只看只出现过一次的值，比如孤立的订单号：

```bash
sort orders.csv | uniq -u
```

忽略大小写判重；行首 20 个字符是时间戳，用 `-s 20` 跳过它，只看后面的正文：

```bash
sort names.txt | uniq -ci
sort app.log | uniq -c -s 20
```

## 注意事项

- `uniq` 只看相邻的行，输入必须先 `sort`；直接对未排序文件用，重复行会被原样留着。
- 比较是按整行字节来的：行尾多一个空格、Tab 和空格混用都会被判成不同行，先 `sed 's/[[:space:]]*$//'` 清洗一遍。
- `-d` 只输出重复组，出现过一次的行不会打印；要同时看两类就分别跑 `uniq -d` 与 `uniq -u`。
- `-c` 的输出是"次数 + 空格 + 原始行"，原始行里也有空格时别用 `cut -d' ' -f1` 取次数，交给 `awk '{print $1}'` 更稳。

## 相关命令

- `sort -u` — 排序阶段直接去重，不关心次数时更省事
- `cut` — 先把要统计的那一列取出来
- `wc -l` — 只想知道去重后有多少行
