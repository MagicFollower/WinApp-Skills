# grep — 按模式检索文本

> 在文件或目录里查找匹配模式的行，支持基本/扩展正则、上下文显示和递归搜索。

## 语法

```bash
grep [选项] 模式 [文件...]
grep [选项] -e 模式1 -e 模式2 文件
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-i`, `--ignore-case` | 忽略大小写 |
| `-v`, `--invert-match` | 反选，输出不匹配的行 |
| `-n`, `--line-number` | 每行结果前加上行号 |
| `-r`, `--recursive` | 递归搜索目录，只跟随命令行上给出的符号链接 |
| `-E`, `--extended-regexp` | 按扩展正则解释模式，`+ ? ( ) \| {n,m}` 不用加反斜杠 |
| `-F`, `--fixed-strings` | 按固定字符串匹配，模式里的 `.` `*` 不再有特殊含义 |
| `-A NUM` | 显示匹配行之后的 NUM 行 |
| `-B NUM` | 显示匹配行之前的 NUM 行 |
| `-C NUM` | 前后各显示 NUM 行，等价于同时给 `-A` 和 `-B` |
| `-o`, `--only-matching` | 只输出匹配到的那一段，一行里有多处就分多行输出 |
| `-c`, `--count` | 只输出匹配的行数，一行匹配多次也只算一行 |
| `-l`, `--files-with-matches` | 只输出含匹配行的文件名，配合 `-r` 快速定位 |

## 示例

搜日志里的内网 IP，用 `-F` 避免点号被当成正则元字符：

```bash
grep -Fn '10.0.0.12' /var/log/nginx/access.log
```

挑出 5xx 响应并带前后各两行上下文，不同匹配组之间会插入一行 `--` 作分隔：

```bash
grep -E -n -C 2 ' 5[0-9]{2} ' /var/log/nginx/access.log
```

配置文件里去掉注释和空行，只看真正生效的配置：

```bash
grep -vE '^[[:space:]]*(#|$)' /etc/fstab
```

把访问来源 IP 抽出来排名，`-o` 是这里的关键：

```bash
grep -oE '^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' access.log | sort | uniq -c | sort -nr
```

递归搜源码，只搜 `.ts` 文件并列出文件名：

```bash
grep -rln --include='*.ts' 'useState' src/
```

## 注意事项

- 模式以 `-` 开头会被当成选项解析，请用 `grep -e '-pattern'` 或 `grep -- '-pattern'`。
- 模式一定要用单引号包住，写成双引号时 `$`、`` ` ``、`\` 会先被 shell 吃掉一层。
- `-c` 统计的是匹配的行数而不是匹配次数，`grep -o ... | wc -l` 才是次数；整词匹配请加 `-w`，`-x` 则要求整行匹配。
- 二进制文件只会提示 "Binary file xxx matches"，想强制按文本搜加 `-a`，想跳过加 `-I`；递归时配合 `--exclude-dir=.git` 更快。
