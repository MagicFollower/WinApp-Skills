# 7z — 多格式压缩（p7zip）

> p7zip 的 `7z` 用 LZMA/LZMA2 换取高压缩率，一条命令读写 7z、zip、tar、gz、bz2、xz 等多种格式，并支持分卷与头部加密。

## 语法

```bash
7z 命令 [-选项...] 归档名 [成员/路径...]
7z a -mx=9 release.7z build/       # 添加到归档
7z x release.7z -o/opt/app         # 保留目录结构解压
7z l release.7z                    # 列出内容
```

## 常用命令与选项

| 写法 | 说明 |
| --- | --- |
| `a` | 创建归档或向已有归档添加条目 |
| `x` | 解压并还原归档内的目录结构 |
| `e` | 解压但把所有成员平铺到当前目录 |
| `t` | 测试完整性，不写任何文件 |
| `d` | 从归档中删除成员 |
| `l` | 列出内容，加 `-slt` 输出可解析的详细字段 |
| `-mx=0`…`-mx=9` | 压缩级别（也可写 `-mx9`），`-mx=0` 只存储 |
| `-t7z` / `-tzip` / `-ttar` | 指定归档格式，省略时按扩展名推断 |
| `-p` / `-pPASS` | 交互式提示密码 / 命令行给密码（同机用户可用 `ps` 看到）；`-mhe=on` 另可加密 7z 归档的文件名头部，须配合 `-p` |
| `-o目录` | 解压目标目录，**`-o` 与路径之间不能有空格** |
| `-y` | 所有确认自动回答 Yes |
| `-x!模式` / `-xr!模式` | 排除路径模式，`-xr!` 递归匹配子目录 |
| `-v2g` | 生成固定大小的分卷，如 `归档.7z.001`、`.002` |
| 格式支持 | 读取 7z、zip、tar、gz、bz2、xz、lzma、rpm、deb、iso、cab、chm、wim、xar 等；写入 7z、zip、tar，xz/lzma 这类单流格式只接受单个文件 |

## 示例

创建高压缩率归档，`7z` 对目录本身就递归处理，`-x!` 排除测试数据与日志：

```bash
7z a -t7z -mx=9 release.7z build/ -x!build/tmp -x!'*.log'
```

按原结构解压到指定目录，同名文件直接覆盖；只想取出一个成员时用 `e` 平铺：

```bash
7z x release.7z -o/opt/app -y
7z e release.7z build/config.yaml -o/tmp/inspect -y
```

校验、查看，以及带密码归档的处理（`-p` 不给值则交互输入）：

```bash
7z t release.7z
7z l -slt release.7z | head -40
7z x -p archive.7z -o/tmp/out
```

单文件超过 FAT32 等介质的 4 GB 上限时切成分卷，接收方对着第一卷解压即可自动续卷：

```bash
7z a -v2g -mx=1 disk.7z huge-backup.tar.xz
7z x disk.7z.001 -o/restore
```

## 注意事项

- `.tar.gz`、`.tar.xz` 这类双层归档 `7z x` 会一次解到底；反过来创建时 `-ttar`、`-t7z` 才是打包格式，gz/bz2/xz 属于单流压缩，整个目录请用 `tar -czf` 一类原生命令。
- `-o` 必须紧跟目录名不留空格，`-o /tmp/x` 会被当成无效选项；路径含空格要写成 `-o"/tmp/my dir"`。
- 只有 7z 格式支持头部加密（`-mhe=on`）和 AES-256；给 zip 格式设 `-p` 走的是弱加密，不能当保密手段。
- 默认固实压缩（solid）压缩率高，但取出单个成员要解压它前面的数据，频繁随机取文件时加 `-ms=off`；RAR/RAR5 只有只读支持，且解码模块常被发行版拆进单独的非 free 包，未安装时 `7z l x.rar` 会报未知格式。

## 相关命令

- `7za` / `7zr` — 独立版可执行文件，`7zr` 只处理 7z 格式
- `tar` / `gzip` / `xz` — Linux 上更常见的原生组合
- `zip` / `unzip` — 跨平台交换格式，7z 可直接读写；`split` 则是不依赖 7z 的分卷方案
