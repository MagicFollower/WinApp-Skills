# top：进程实时视图

> 循环刷新系统摘要与进程列表，交互键即可完成排序、展开线程、发信号。

## 语法

```bash
top [选项]
top -b -n 1              # 批处理输出一帧，供脚本采集
top -H -p <PID>          # 只监视某进程的线程
top -o <列键>            # 启动即按指定列排序
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-d`, `-s <秒>` | 刷新间隔，支持小数（如 `-d 0.5`） |
| `-n <次数>` | 迭代多少次后退出，采集场景与 `-b` 同用 |
| `-b` | 批处理模式，便于重定向或接管道 |
| `-c` | 显示完整命令行而非截断的程序名 |
| `-p <PID,...>` | 监视列表，`-p 0` 恢复显示全部进程 |
| `-u <用户>` | 按用户筛选进程 |
| `-o <键>` | 启动时排序列，取表头缩写，如 `%CPU`、`%MEM`、`TIME+` |
| `-w <宽>` | 指定输出宽度，`-w 512` 防长命令被截断 |

### 交互键

| 键 | 说明 |
| --- | --- |
| `1` | 展开/合并每个 CPU 核心的独立统计 |
| `P` | 按 %CPU 降序（默认） |
| `M` | 按内存占用（RES）降序 |
| `H` | 线程模式，逐 LWP 显示 |
| `k` / `r` | 交互式给某 PID 发送信号（默认 SIGTERM）/ renice |
| `u` | 按用户名过滤，命令行 `-u` 等价 |
| `z` | 开关颜色，大写 `Z` 打开配色面板 |
| `q` | 退出，`Ctrl+C` 亦可 |

## 示例

线上突发卡顿先留一帧现场数据，比事后回忆更有用。
```bash
top -b -n 1 -w 512 > /tmp/top.$(date +%F_%H%M)
```

Java 进程吃满 CPU，用线程模式定位到具体线程号。
```bash
top -H -p "$(pgrep -o java)"
```

按内存降序观察 10 个周期，判断是否持续泄漏。
```bash
top -b -d 5 -n 10 -o %MEM > /tmp/top-mem.log
```

同机部署时只保留数据库相关进程，减少干扰。
```bash
top -u postgres
```

## 注意事项

- `%CPU` 在 Irix 模式下可超过 100%（多核算加），按 `I` 切到 Solaris 模式则除以核数；`1` 只影响每核摘要。
- 判断真实占用看 `RES`，`VIRT` 含映射与共享内存，可能远大于物理占用；`T` 按累计 CPU 时间排序、`c` 切换命令行、`Space` 立即刷新，`W` 把当前列与排序写进 `~/.toprc`。
- `k`、`r` 受权限约束：普通用户只能对自己拥有的进程发信号或调高 nice 值，操作他人进程需 root。
- 交互键属于 procps-ng 的 `top`，BusyBox 或旧实现可能缺 `H`、`-o`、`z`；容器里界面错乱可设 `TERM=xterm`，按 `q` 退出后用 `top -b` 采集。

## 相关命令

- `ps` — 一次性进程快照
- `htop` — 带鼠标与横向滚动的增强视图
- `vmstat` — CPU/内存/IO 整体趋势
- `pidstat` — 按 PID 间隔采样
