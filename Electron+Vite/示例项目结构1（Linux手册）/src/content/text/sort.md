# sort — 按键排序、数值排序与去重

> 把文本按指定列、指定规则排好序输出，支持数值、人类可读单位、版本号和字段分隔符。

## 语法

```bash
sort [选项] [文件...]
sort [选项] -k POS1[,POS2] 文件
命令 | sort [选项]
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-k`, `--key=POS1[,POS2]` | 按列排序，列号从 1 开始；`-k 2,2` 只比第 2 列，`-k 2` 比到行尾 |
| 键尾标志 | 位置后面可直接跟排序标志，如 `-k 3,3nr` 表示第 3 列数值降序 |
| `-n`, `--numeric-sort` | 按数值比较，`10` 排在 `9` 之后 |
| `-h`, `--human-numeric-sort` | 认 `K`、`M`、`G` 这类单位，配合 `du -h`、`ls -lh` |
| `-g`, `--general-numeric-sort` | 按浮点数比较，支持 `1e6`、`nan`，比 `-n` 慢 |
| `-M`, `--month-sort` | 按 `Jan`、`Feb` 这样的月份名排序 |
| `-V`, `--version-sort` | 自然序排版本号，`1.10` 排在 `1.9` 之后 |
| `-r`, `--reverse` | 把最终结果整体倒序 |
| `-t`, `--separator=C` | 指定列分隔符，`-t,` 即按逗号切列 |
| `-u`, `--unique` | 每组只输出第一条，判重范围就是参与排序的键 |
| `-s`, `--stable` | 键相同时保持输入顺序，否则退化为整行比较 |
| `-o 文件` | 结果写文件，可以安全地写回输入文件自身 |
| `-S`, `--buffer-size=SIZE` | 设置内存缓冲，如 `-S 512M`；`-T 目录` 指定临时文件位置 |

## 示例

按第 3 列数值降序取销售额前 10 名，`-t,` 负责切列：

```bash
sort -t, -k3,3nr sales.csv | head -n 10
```

目录占用从大到小，`-h` 直接吃 `du -sh` 出来的 `1.2G` 这种写法：

```bash
du -sh /var/log/* | sort -hr
```

先按第 1 列升序、再按第 2 列数值降序；版本号列表用 `-V` 更自然：

```bash
sort -k1,1 -k2,2nr report.tsv
sort -V tags.txt
```

去重和排序一步做完；大文件调大缓冲并把临时文件放到空间充足的分区：

```bash
sort -u -t, -k1,1 hosts.csv
sort -S 512M -T /var/tmp data.tsv -o data.tsv
```

## 注意事项

- `-k2` 和 `-k2,2` 不是一回事：省略结束位置时键一直延伸到行尾，第 2 列相同的行会继续由第 3 列决定顺序。
- 把数值标志写进键说明（`-k 2,2n`）比全局 `-n` 更可预测；全局 `-n` 是拿每行开头的数字做比较。
- 排序结果受区域设置影响，写测试用例或跟别人比对输出时统一加 `LC_ALL=C`，大小写与重音的次序才不会变。
- 指定 `-k` 后 `-u` 只按这些键判重；要求整行完全相同才算重复就别给 `-k`。字段前的空白参与比较时，加 `-b` 忽略前导空白。

## 相关命令

- `uniq` — 折叠排序后相邻的重复行并计数
- `cut` — 排序前先把需要的列取出来
- `comm` — 比较两个已排序文件
