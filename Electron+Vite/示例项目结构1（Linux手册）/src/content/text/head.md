# head — 查看文件开头若干行或字节

> 只读文件开头就输出，默认前 10 行；用 `-n` 改行数，用 `-c` 改字节数。

## 语法

```bash
head [选项] [文件...]
head -n NUM 文件
head -c NUM 文件
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-n`, `--lines=NUM` | 输出前 NUM 行，省略时默认 10 行 |
| `-n -NUM` | GNU 扩展：输出除末尾 NUM 行之外的全部内容 |
| `-c`, `--bytes=NUM` | 按字节输出前 NUM 个，带 `K`、`M`、`G` 等后缀表示 1024 的倍数 |
| `-q`, `--quiet`, `--silent` | 多文件时不打印 `==> 文件名 <==` 头部 |
| `-v`, `--verbose` | 只有一个文件时也强制打印文件名 |
| `-z`, `--zero-terminated` | 以 NUL 而不是换行分隔行，配合 `find -print0` |

## 示例

确认配置文件写对了没有，先看开头几行：

```bash
head -n 15 /etc/nginx/nginx.conf
```

多个文件一起看，默认自带文件名头部，正好用来对比不同环境的差异：

```bash
head -n 3 prod/*.conf
```

只取前 64 个字节判断文件类型，交给 `od` 打印十六进制：

```bash
head -c 64 upload.bin | od -An -tx1
```

取 CSV 的表头加第一条数据，发给同事确认字段顺序：

```bash
head -n 2 sales.csv
```

丢掉日志末尾可能写了一半的 5 行再统计错误数：

```bash
head -n -5 run.log | grep -c 'ERROR'
```

## 注意事项

- `-c` 是按字节切的，UTF-8 中文可能被切成半个字符，输出里出现乱码属正常。
- `head -n -NUM` 必须读到文件末尾才知道"最后 NUM 行"，省不了 I/O；只有正数行数才会提前停止读取。
- 行数以换行符为准：末行不带换行时 `head` 照样输出它，但 `wc -l` 不计这一行。
- 管道给 `sort`、`grep` 之前记得加 `-q`，否则 `==> xxx <==` 这行会混进数据里。

## 相关命令

- `tail` — 查看末尾并跟踪追加
- `cat` — 一次性输出整个文件
- `less` — 分页浏览，可前后搜索
