# sed — 流编辑器：替换、删除与打印

> 逐行读入、按地址执行脚本再输出；改配置、抽字段、批量替换都用它，不需要把整个文件装进内存。

## 语法

```bash
sed [选项] '脚本' [文件...]
sed [选项] -e 脚本1 -e 脚本2 文件
sed [选项] -f 脚本文件 文件
```

## 常用选项

| 选项 | 说明 |
| --- | --- |
| `-i[SUFFIX]` | 原地修改文件；GNU sed 可以不写后缀，`-i.bak` 会留下备份文件 |
| `-n`, `--quiet`, `--silent` | 关闭默认输出，只打印脚本里显式 `p` 的内容 |
| `-e 脚本` | 一次给出多个脚本，按顺序作用在同一行上 |
| `-f 脚本文件` | 从文件读取脚本，逻辑复杂时比引号套引号清楚 |
| `-E`, `-r` | 按扩展正则解释模式和地址，GNU sed 中两个写法等价 |
| `-z`, `--null-terminated` | 用 NUL 而不是换行分隔记录，配合 `find -print0` |
| `--posix` | 关掉 GNU 扩展，用来检查脚本的可移植性 |

## 示例

替换整行所有出现，用 `|` 当分隔符就不必转义 URL 里的斜杠：

```bash
sed 's|http://|https://|g' urls.txt
```

只打印 `[nginx]` 到下一个 `[` 之间的段落，区间地址会匹配每一个这样的区间：

```bash
sed -n '/^\[nginx\]/,/^\[/p' app.ini
```

去掉注释行和空行，只看生效的配置：

```bash
sed '/^[[:space:]]*#/d;/^[[:space:]]*$/d' /etc/ssh/sshd_config
```

用 `-E` 和捕获组交换 CSV 的前两列，`\1`、`\2` 回引括号内容：

```bash
sed -E 's/^([^,]+),([^,]+),/\2,\1,/' ranks.csv
```

改配置留备份，并在首行前插入一行说明；`1i` 后直接跟文本是 GNU sed 的写法：

```bash
sed -i.bak 's/^debug = true/debug = false/' app.ini
sed -i '1i # 由发布脚本生成' CHANGELOG.md
```

## 注意事项

- `-i` 是"写临时文件再改名替换"，inode 会变：`tail -f` 会跟丢、硬链接会断开、原文件的属主和权限也可能变化。动手前先跑一遍不带 `-i` 的版本确认输出。
- macOS 上的 BSD sed 与 GNU sed 不通用，BSD 的 `-i` 必须紧跟备份后缀（`sed -i '' 's/a/b/' f`），跨平台脚本不要指望同一行命令两边都能跑。
- 替换串里的 `&` 表示"整段匹配到的内容"，想输出字面 `&` 要写成 `\&`；只想替换全文件第一次出现时，用 GNU 扩展地址 `0,/模式/`。
- `s` 不加 `g` 只替换每行第一个匹配；`-n` 之后没有 `p` 就一行都不会输出，调试时先把 `p` 加上。

## 相关命令

- `grep` — 只查找不改内容时更直接
- `awk` — 需要按列做判断和统计时更合适
- `tr` — 单字符集合的一一对应替换
